# 三大核心功能说明

本文档说明"无土栽培智能教学助手"的三个核心功能：**自动复制 Prompt**、**自动提问（发送到 DeepSeek）**、**自动分享（生成二维码）**的实现原理与使用方法。

---

## 一、自动复制（Prompt 一键复制）

### 功能描述

教师在侧边栏点击任意 Prompt 右侧的【复制】按钮，或选中某个 Prompt 后点击底部【📋 复制 Prompt】大按钮，完整的无土栽培教学提示词会立即写入系统剪贴板，并弹出"Prompt 已复制"提示。教师到 DeepSeek 输入框按 `Ctrl+V` 即可粘贴发送。

### 使用流程

```
点击 Prompt 选中 → 点击【📋 复制 Prompt】→ 提示"Prompt 已复制" → 到 DeepSeek 按 Ctrl+V 粘贴 → 发送
```

### 技术实现

- 剪贴板使用 **Electron 官方 Clipboard API**（主进程 `clipboard.writeText()`），见 `src/main/main.js` 的 `prompt:copy` IPC 处理器
- 渲染层通过 `contextBridge` 暴露的 `window.api.copyPrompt(text)` 调用（`src/main/preload.js`）
- **纯本地操作**：Prompt 不上传任何服务器，不写入远程数据库，无网络请求

### 涉及代码

| 位置 | 作用 |
|------|------|
| `src/renderer/src/App.jsx` → `PROMPTS` 数组 | 7 个无土栽培教学 Prompt 模板 |
| `src/renderer/src/App.jsx` → `copyPrompt()` | 复制并弹出提示 |
| `src/main/main.js` → `ipcMain.handle('prompt:copy')` | 调用 Electron clipboard 写入剪贴板 |

## 二、自动提问（发送到 DeepSeek：自动填入 + 自动发送）

### 功能描述

教师选中一个 Prompt 后点击【🚀 发送到 DeepSeek】：

1. 助手自动激活已内嵌 DeepSeek 的窗口区域
2. Prompt 自动填入 DeepSeek 的输入框
3. 自动触发发送（模拟回车）
4. DeepSeek 开始生成回答，教师无需打字

### 使用流程

```
选中 Prompt（如"植物病害分析"）→ 点击【🚀 发送到 DeepSeek】→ 输入框自动填入 → 自动发送 → DeepSeek 回答
```

### 技术实现

自动化逻辑**集中在一个独立模块** `src/renderer/src/deepseekAutomation.js`，DeepSeek 网页日后改版只需修改这一个文件。

通过 Electron `<webview>` 的 `executeJavaScript()` 在 DeepSeek 页面内执行**最小化 DOM 操作**，只做三件事：

1. **定位输入框**：优先 `textarea#chat-input`，其次任意 `textarea`，最后 `contenteditable` 富文本框
2. **写入 Prompt**：使用原生 value setter + `input` 事件（兼容 React 受控组件）
3. **触发发送**：派发 `Enter` 键盘事件，并在 0.9 秒后检查输入框是否被清空来判断发送是否成功

### 安全边界（重要）

- ❌ 不自动登录、不获取密码、不读取 Cookie/Token
- ❌ 不调用 DeepSeek 未公开接口，不修改页面其他内容
- ✅ 只操作输入框和回车键，登录仍由教师本人完成（登录状态持久化在本机）

### 失败兜底（自动化不影响软件运行）

| 情况 | 软件行为 |
|------|----------|
| DeepSeek 页面未加载完 | 提示"请先打开 DeepSeek" |
| 找不到输入框（未登录/改版） | 提示"自动填写失败，请点击复制 Prompt 后手动粘贴" |
| 填入成功但未触发发送 | 提示"已填入输入框但未自动发送，请按回车发送" |
| 任何异常 | 仅弹提示，主进程不崩溃，复制功能始终可用 |

**备用流程永远可用**：复制 Prompt → 手动粘贴 → 发送。

### 涉及代码

| 位置 | 作用 |
|------|------|
| `src/renderer/src/deepseekAutomation.js` | 全部自动化逻辑（独立模块） |
| `src/renderer/src/App.jsx` → `sendToDeepSeekNow()` | 调用自动化并按结果提示 |

## 三、自动分享（生成二维码）

### 功能描述

教师在 DeepSeek 中使用**官方分享功能**复制对话链接，粘贴到助手的"DeepSeek 分享链接"输入框，点击【生成二维码】：

1. 立即生成并显示二维码预览
2. 点击【保存二维码】，图片自动保存到 `桌面\无土栽培AI助手\二维码\`
3. 同时自动写入教学记录（时间 + 备注 + 链接）

### 使用流程

```
DeepSeek 对话 → 点"分享"复制链接 → 粘贴到输入框 → 点击【生成二维码】→ 显示预览 → 点击【保存二维码】→ 保存到桌面
```

### 技术实现

- 二维码使用 **`qrcode` npm 包**在前端生成（Data URL 图片），不搭建服务器、不上传数据
- 保存位置：`桌面/无土栽培AI助手/二维码/`，目录不存在时自动创建（`fs.mkdirSync(recursive)`）
- 文件名自动命名为 `AI对话分享_YYYYMMDD_HHmmss.png`（如 `AI对话分享_20261004_213015.png`）
- 链接校验：空链接提示"请先输入 DeepSeek 分享链接"；非 `https://chat.deepseek.com/share/...` 格式提示"请输入有效的 DeepSeek 分享链接"
- 每次生成自动保存一条本地记录（JSON 文件，仅含时间/备注/链接，不含登录信息）

### 涉及代码

| 位置 | 作用 |
|------|------|
| `src/renderer/src/App.jsx` → `generateQr()` / `saveQr()` | 生成预览、调用保存 |
| `src/main/main.js` → `ipcMain.handle('qr:save')` | 创建目录、按时间戳命名、写入 PNG 文件 |
| `src/main/main.js` → `records.json` 读写 | 本地教学记录 |

## 四、课堂完整演示流程（比赛模式）

```
启动软件 → 点击【开始使用 AI】→ 出现桌面悬浮球 🌱
    ↓
点击悬浮球 → 打开助手 → 选中 Prompt → 点击【🚀 发送到 DeepSeek】
    ↓
DeepSeek 自动回答（教师可继续正常对话）
    ↓
点击 DeepSeek 官方"分享" → 复制链接
    ↓
回到悬浮助手 → 粘贴链接 → 【生成二维码】→【保存二维码】
    ↓
评委扫码查看完整对话
```
